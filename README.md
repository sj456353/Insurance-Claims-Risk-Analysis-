# Insurance Claims Risk Analysis

Python analysis of a medical insurance dataset (1,338 records) exploring key risk factors — smoking status, age, and BMI — that drive up claim costs.

## Tools
Python, pandas, matplotlib (via Google Colab)

## Key Findings
- Smokers pay 3.8x more on average than non-smokers (£32,050 vs £8,434)
- Charges rise with age within both groups, but the smoker/non-smoker gap persists at every age
- Among smokers, obesity nearly doubles average charges (£41,693 vs £21,369) — smoking and BMI compound each other
